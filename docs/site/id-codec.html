ID 雙向轉碼工具

僅處理 Excel B 欄「序號」與 C 欄「轉碼後ID」，不使用 D 欄。

資料僅在本機處理
轉碼方式研究結論：目前尚未識別出可適用未知 ID 的原始加解密演算法或金鑰。此工具目前採用本機匯入對照資料的精確雙向轉換，不猜測不存在的映射，也不把對照檔上傳至 GitHub 或其他伺服器。
