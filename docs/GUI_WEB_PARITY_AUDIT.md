# AUDIO 桌面 GUI → GitHub Pages 逐項功能、操作邏輯差異（2026-11-27）

## 範圍及安全原則
只以 `hub-google/audiobook-generator` 的 `main`、GitHub Pages、既有 GitHub Actions 為範圍。本盤點**不變更**任何 Cloudflare、DNS 或外部服務。GitHub Pages 只有靜態 HTML/CSS/JS，**不能安全保存 GitHub 寫入權限金鑰**；所有放入前端 JS 的常數、隱藏欄位、瀏覽器記憶體或網路請求，都可能被 DevTools 看見。GitHub Actions Secrets 只能供 Actions 內執行的程式讀取，**無法**讓匿名 GitHub Pages 安全呼叫寫入 API。因此目前「完全免輸入 Token + 網頁內完全操作」仍未達成，不能宣稱全功能移植完畢。現有前端的 Token 輸入／記憶體方式亦不符合使用者最新要求，需有真正伺服器端身份驗證及代理（使用者禁止新增其他平台，故此部分不擅自另起服務）。

## 驗收原則
- 桌面 GUI 的**前置條件、狀態轉換、後製門檻、Profile/Queue 雙寫、Run 回復**，不能因為換成網頁就改弱。
- 不應將沒有正式權限或無法執行的按鈕標示為「已完成」。
- 任何 Secrets（GitHub、HF、Gemini、YouTube）不允許打包進 Pages Artifact、HTML、JS、DevTools 可讀回應。
- 一切變更都須 `main` CI 與桌面／手機實際瀏覽器測試成功；拒絕只以靜態存在元素作為驗收。
