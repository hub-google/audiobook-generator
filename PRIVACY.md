# Privacy Policy for Audiobook Studio Automation

**Last Updated: August 2026**

## 1. Overview
Audiobook Studio Automation ("we", "our", or "the Application") is an internal automation tool designed for generating and publishing long-form audiobooks to YouTube.

## 2. Information Accessed & Collected
- The Application uses YouTube API Services (YouTube Data API v3) solely to automate the upload of videos, thumbnails, captions (subtitles), and playlist management to the authorized YouTube channel.
- We access channel authentication credentials via Google OAuth 2.0. These credentials are used strictly for automated publishing tasks.
- The Application does not collect, store, sell, or share any personal user data with third parties.

## 3. Use of Google & YouTube API Data
- Access to YouTube data strictly complies with the Google API Services User Data Policy (https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
- We adhere to the YouTube Terms of Service (https://www.youtube.com/t/terms) and Google Privacy Policy (https://policies.google.com/privacy).

## 4. Data Retention and Revocation
- OAuth credentials and permissions can be revoked by the user at any time via Google Account Security Settings (https://myaccount.google.com/permissions).
